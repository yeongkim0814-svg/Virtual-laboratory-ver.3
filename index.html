가상 실험실

물리 · 화학 법칙을 직접 확인하는 1인칭 실험실

  • 이동 화면 왼쪽을 누른 채 밀기 (PC: WASD)
  • 둘러보기 화면 오른쪽 드래그 (PC: 마우스 드래그)
  • 집기 물체를 탭 (PC: 클릭 / E)
  • 놓기·연결 들고 있을 때 책상이나 다른 기구를 탭
  • 기구 오른쪽 벽 보관장의 문을 열어 꺼내기
