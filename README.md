# 가상 실험실 (Virtual Laboratory)

갤럭시 탭에서 브라우저로 접속하는 1인칭 3D 가상 실험실. 물리·화학 법칙을 직접 구현하고 측정하는 것이 목표다.
현재 단계: **2단계 — 기구를 직접 꺼내 조립하는 실험실: 단진자 · 용수철 진자 + 이중 슬릿 간섭 + 광전 효과 + 역학 레일(수레 충돌·가속) + 3단계 화학(산·염기)** (화면 16:9 고정, PS1 시대 레트로 그래픽)

## 조작

| | 태블릿 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 40%를 누른 채 밀기 (조이스틱) | WASD / 방향키 |
| 둘러보기 | 나머지 영역 드래그 | 마우스 드래그 |
| 집기·문 열기 | 물체를 **한 번 탭** (화면 어디든) | 클릭 / E |
| 놓기 | 들고 있을 때 책상·바닥을 한 번 탭 (호박색 고리 = 가능, 빨강 = 불가) | 클릭 / E |
| 조작 | 놓인 기구를 **두 번 탭** (또는 길게 누르기) → 실험 열기·전원·켜기·전압·파장·회전·높이·도선·밀기 메뉴 | |
| 끼우기·매달기 | 들고 있을 때 다른 기구를 **두 번 탭** | |

조준점 아래에는 조준한 장비의 이름만 표시된다. 조작 방법은 오른쪽 위 **?** 버튼의 도움말 페이지에 있다.
한 번 탭은 두 번째 탭을 0.3초 기다렸다가 실행된다 (그 자리에 두 번 탭 동작이 없으면 바로).

## 실험 방법: 기구를 꺼내 직접 조립한다

기구는 **주 실험실 오른쪽 벽의 보관장**에 있다. 문을 탭해 열고 꺼낸다.

| 칸 | 기구 |
|---|---|
| 1·2 (긴 칸) | 스탠드 4개 |
| 3 | 클램프 4개 |
| 4 | 실, 각도기 · 아래 둘째 칸: 용수철 k 10 N/m (m_s 12 g), k 25 N/m (m_s 20 g) |
| 5 | 추 50 g · 100 g · 200 g · 아래 둘째 칸: 추 20 g · 150 g |
| 6 | 쇠공, 추 100 g |
| 7 (위) | 레이저 (650 · 532 · 405 nm 선택), 스크린 |
| 8 (위) | 이중 슬릿 d 0.10 · 0.20 mm, 단일 슬릿 a 0.10 mm |
| 7 (아래 둘째 칸) | 직류 전원 장치 (0~5 V) |
| 8 (아래 둘째 칸) | 마이크로 전류계, 광전관 세슘(W 2.14 eV) · 나트륨(W 2.28 eV) |

실험대 아래 수납장(양쪽 긴 면), 뒤쪽 벽 수납장, 폐시약 보관함도 모두 여닫는 칸이다 (준비실은 화학 실험용 — 시약장 추가 예정).
실험 테이블의 문 없는 짧은 옆면에는 **2구 콘센트**가 있다. 전원이 필요한 기기(레이저 등)는 전원선(2 m)이 닿는
콘센트에 꽂아야 작동한다 — 기기를 탭해 "전원 연결", 또는 콘센트를 탭해 "꽂기".

기구끼리는 **플러그 → 소켓**이 맞으면 연결된다. 물체를 든 채 다른 기구를 두 번 탭하면 끼워진다. 조준점 아래에
`[탭] 연결 · 클램프 → 스탠드 막대`처럼 표시된다.

| 들고 있는 것 | 탭할 곳 | 결과 |
|---|---|---|
| 클램프 | 스탠드 막대 (원하는 높이) | 그 높이에 고정, 팔이 나를 향함 |
| 실 | 클램프 집게 | 실이 늘어짐 |
| 용수철 | 클램프 집게 | 용수철이 매달림 (자기 무게로 조금 늘어남) |
| 추·쇠공 | 실 끝 고리 | 매달림 → **진자** |
| 추·쇠공 | 용수철 아래 고리 | 매달림 → **용수철 진자** |
| 추·쇠공·실·플라스크·레이저·광전관 | 클램프 집게 | 집게에 단단히 고정 |
| 슬릿판·스크린 | 클램프 집게 | 판 옆 가장자리를 물어 **세로로** 서고, 판이 팔 방향(나)을 향함 → 레이저는 팔 방향으로 쏘면 된다 |
| 각도기 | 클램프 | 받침점 뒤에 세워짐 |

연결된 기구를 들면 거기에 붙은 것도 함께 들린다. 조립된 기구 어디를 두 번 탭해도 **진자 실험** 등이 메뉴에 뜨고,
화면 왼쪽 위의 `▸ 진자 실험`, `▸ 간섭무늬 관찰` 버튼으로도 바로 열 수 있다.
두 번 탭 메뉴: 회전(1° 단위, 슬라이더는 15°의 배수 ±2°에서 붙음), 클램프 높이 ±1 cm,
레이저 파장·출력(1·3·5 mW), 전원 연결·뽑기, 도선 연결 시작·빼기.
오른쪽 위 🔍 버튼은 시야를 약 4배 확대한다 (mm 단위 무늬·눈금 보기).

### 이중 슬릿 간섭
레이저·슬릿판·스크린을 책상 위에 한 줄로 세우거나(높이가 맞게 만들어져 있음), 스탠드 + 클램프로 원하는 높이에 고정한다.
클램프를 막대에 끼울 때 `(높이 n cm)`가 표시된다 — 레이저 빛 높이는 책상에서 3.5 cm.
레이저를 콘센트에 꽂고 켜면 빛을 광선 추적으로 따라간다. 슬릿 중심에서 가로 ±2 cm, 세로 ±3 cm 안에 닿으면
미세 조정된 것으로 보고 통과해 회절·간섭된다 (벗어나면 왼쪽 위에 "빛이 슬릿 중심보다 … 를 지남" 안내).
무늬는 스크린뿐 아니라 벽·가구 등 빛이 닿는 어떤 면에도 고해상도 데칼로 비친다. Δy = λL/d 이므로 멀리 비출수록 넓다.
관찰 패널에서 확대된 무늬에 커서 A, B를 놓고 간격 수 n을 정하면 Δy = |B−A|/n, λ = d·Δy/L를 계산한다.
세기 분포는 I = I₀·cos²(πd sinθ/λ)·(sin β/β)², β = πa sinθ/λ.

### 역학 레일 · 수레
뒤쪽 벽 낮은 수납장 안(문을 열어 꺼냄)에 레일(1.2 m, cm 눈금, 오른쪽 끝 넓은 칸), 수레 A·B(각 500 g), 질량 막대 250 g × 4, 운동 센서 2개가 있다.
레일을 책상에 놓고 → 수레를 들고 레일을 두 번 탭(탭한 자리에 올라감) → 질량 막대를 들고 수레를 두 번 탭.
수레를 두 번 탭: 밀기 → / ←, 멈추기, 범퍼(자석 e≈0.95 · 용수철 e≈0.85 · 벨크로 달라붙음). 레일 두 번 탭: 기울기 ±0.5°.
`▸ 궤도 실험` 패널: 기울기 0 ~ 10°, 구름 저항 μ, 재생 속도(¼×까지·멈춤), 수레별 범퍼·미는 속력, 처음 자리로.
속도·가속도는 일부러 보여 주지 않는다 — 센서(추후)로 측정. 계산은 a = −g sinθ − μg cosθ·sign(v),
충돌은 운동량 보존 + 반발 계수 e (sim/track.ts), 수레별 (t, s, v)와 충돌 기록을 남겨 둔다.

### 화학 (준비실) — 산·염기, 지시약, pH
**시약장**(준비실 왼쪽): 0.1 M HCl · NaOH · CH₃COOH · NH₃, 증류수 2병, 지시약 3종(페놀프탈레인·메틸 오렌지·BTB), 만능 pH 시험지.
**유리 기구 보관장**(오른쪽): 뷰렛 2, 스탠드·클램프, 비커 6, 삼각 플라스크 2, 눈금실린더 2.
- 그릇을 들고 시약병 두 번 탭 → **받기**, 다른 그릇 두 번 탭 → **따르기** (슬라이더 한 칸 = 두 그릇 중 더 정밀한 눈금: 눈금실린더 0.5 mL, 뷰렛 0.05 mL, 비커 5 mL, 플라스크 10 mL). 시약병에는 다시 붓지 않는다.
- 지시약병을 들고 그릇 두 번 탭 → 1~3방울. pH 시험지 → 비교표로 읽은 대략의 pH(정수).
- 뷰렛: 클램프에 물리고 그릇을 끝 바로 아래 → 뷰렛 두 번 탭 → **적하**. 눈금은 위가 0 (읽은 값 = 50 − 들어 있는 양).
- 그릇 두 번 탭 → 눈금 읽기(그릇 정밀도만큼)와 색. 다 쓴 용액은 폐시약 보관함 위 **폐액통**에.

계산 (sim/chem.ts): 용액 = 부피 + 보존되는 성분 몰수(Na⁺, Cl⁻, 아세트산 총량, 암모니아 총량, 지시약).
pH는 전하 균형 [H⁺] + [Na⁺] + [NH₄⁺] = [OH⁻] + [Cl⁻] + [CH₃COO⁻]를 이분법으로 풀어 구한다 → 중화·약산·완충·가수분해를 한 식으로.
지시약 색은 비어-람베르트 흡광(A = ε·c·l, 투과율 10⁻ᴬ)을 빨강·초록·파랑으로 나눠 계산 → 섞인 지시약도 물리적으로 섞인 색.
한계: 이상 용액(활동도 = 농도), 부피 가산, 25 °C 고정.
검증: 0.1 M CH₃COOH pH 2.87, 반당량점 4.74(= pKa), 당량점 8.72 / HCl 25 mL + NaOH 24.90 → 3.70, 25.10 → 10.30.

### 센서 · 노트북 (측정 프로그램)
노트북은 칠판 앞 교탁 위 2대 + 스탠딩 테이블 위 1대(모두 같은 측정 프로그램). 센서는 노트북에 USB(2 m)로 연결해서 쓴다 (센서 두 번 탭 → 노트북에 연결).
**운동 센서**(초음파): 정면으로 가장 가까운 물체까지의 거리 x (0.15 ~ 3 m, 1 mm 단위). 레일 양 끝의 센서 받침에 끼우면 레일 방향을 본다.
노트북 두 번 탭 → **측정 프로그램**: 기록 시작·멈춤, 표본 10/20/30 Hz, 기록 시간, 계산 창(3 ~ 11점), 방향 반대,
x–t · v–t · a–t 그래프, 커서 A·B 구간의 Δx, 평균 속도, 가속도(x–t 2차 맞춤 / v–t 기울기), CSV.
v·a는 x에서 계산한 값: 창 안 점들의 직선 맞춤 기울기 (창이 넓을수록 매끄럽지만 충돌처럼 빠른 변화는 뭉개짐).
레일을 느리게 돌리면 기록 시각도 같은 배율로 흐르므로 측정값은 실제 물리량 그대로다.

### 용수철 진자
클램프 → 용수철 → 추. 당긴 거리 A를 정하고 **놓기**. 측정 주기 T를 이상적 2π√(m/k), 용수철 질량 보정 2π√((m + m_s/3)/k)와 비교한다.
추를 바꿔 가며 기록하면 **T²–m 그래프**의 기울기(4π²/k)에서 k, 절편에서 용수철 질량 m_s를 구한다.
추가 책상에 닿으면 놓을 수 없고, 탄성 한계를 넘거나 A가 정적 늘어남보다 크면 경고가 뜬다.

### 기록 내보내기·그래프
단진자·용수철 패널의 **CSV** 버튼은 기록 표를 파일로 저장한다 (태블릿의 다운로드 폴더, 엑셀·구글 시트에서 열림).
단진자 기록 그래프: **T–√L** (θ₀ ≤ 20° 기록을 직선 맞춤 → g = (2π/기울기)²), **T/T₀–θ₀** (타원 적분 이론 곡선과 비교).

### 광전 효과
1. 레이저, 광전관, 전류계, 전원 장치를 책상에 놓고 레이저·전원 장치를 콘센트에 연결한다.
2. **도선**: 기구를 두 번 탭 → `도선 연결 시작 · +` → 이을 기구를 한 번 탭 → 단자 고르기 (단자를 직접 탭해도 됨).
   연결 중에는 단자에서 조준점까지 노란 미리 보기 선이 보인다. 빈 곳을 탭하면 취소.
   회로: 전원 + → 전류계 + → 전류계 − → 광전관 양극(A), 광전관 음극(K) → 전원 −. (도선 최대 1.5 m, 단자를 다시 탭하면 빼기. 도선은 빨강(+ 쪽)·파랑, 전원선은 회색. 선은 같은 면 위의 장비를 옆으로 돌아가고(길찾기), 책상 가장자리를 넘어 늘어진다)
3. 레이저를 광전관 창(음극)에 비춘다. 왼쪽 위 `▸ 광전 효과 실험`으로 패널을 연다.
4. 패널에서 전압 슬라이더·±0.01/0.1 V, **극성(정/역)** 으로 V_AK를 바꾸며 I–V 곡선을 그린다.
   역전압을 올려 전류가 0이 되는 전압을 **정지 전압 V_s로 기록** → 파장을 바꿔 반복 → V_s–f 그래프의 기울기에서 h, 절편에서 W.
eV_s = hf − W. 빛이 세지면 포화 전류만 커지고 V_s는 그대로, hf < W 이면(예: 650 nm) 아무리 세도 전류 0.

### 단진자 실험 패널
실 길이 ℓ, 처음 각도 θ₀, 적분 방법, Δt, 공기 저항을 정하고 **놓기**. 진자 길이는
L = ℓ + (고리 ~ 추 무게 중심)으로 자동 계산된다. 추가 책상에 닿는 길이면 실이 자동으로 짧아지고 안내가 뜬다.
측정 주기 T, 작은 각 근사 T₀ = 2π√(L/g), 타원 적분으로 구한 정확한 주기, 역학적 에너지 변화,
θ(t) 그래프, 기록 표를 보여 준다.
