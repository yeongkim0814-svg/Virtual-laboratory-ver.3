# 가상 실험실 (Virtual Laboratory)

갤럭시 탭에서 브라우저로 접속하는 1인칭 3D 가상 실험실. 물리·화학 법칙을 직접 구현하고 측정하는 것이 목표다.
현재 단계: **2단계 — 기구를 직접 꺼내 조립하는 실험실: 단진자 · 용수철 진자 + 이중 슬릿 간섭 + 광전 효과 + 역학 레일(수레 충돌·가속) + 3단계 화학(산·염기)** (화면 16:9 고정, PS1 시대 레트로 그래픽)

## 조작

| | 태블릿 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 40%를 누른 채 밀기 (조이스틱) | WASD / 방향키 |
| 둘러보기 | 나머지 영역 드래그 | 마우스 드래그 |
| 집기·문 열기 | 물체를 **한 번 탭** (화면 어디든) | 클릭 / E |
| 놓기 | 들고 있을 때 책상·바닥을 한 번 탭 (호박색 고리 = 가능, 빨강 = 불가) | 클릭 / E |
| 조작 | 놓인 기구를 **두 번 탭** (또는 길게 누르기) → 실험 열기·전원·켜기·전압·파장·위치·방향·높이·도선·밀기 메뉴 | |
| 끼우기·매달기 | 들고 있을 때 다른 기구를 **두 번 탭** | |

조준점 아래에는 조준한 장비의 이름만 표시된다. 조작 방법은 오른쪽 위 **?** 버튼의 도움말 페이지에 있다.
한 번 탭은 두 번째 탭을 0.3초 기다렸다가 실행된다 (그 자리에 두 번 탭 동작이 없으면 바로).

## 실험 방법: 기구를 꺼내 직접 조립한다

기구는 **주 실험실 오른쪽 벽의 보관장**에 있다. 문을 탭해 열고 꺼낸다.

| 칸 | 기구 |
|---|---|
| 1·2 (긴 칸) | 스탠드 4개 |
| 3 | 클램프 4개 |
| 4 | 실, 각도기 · 아래 둘째 칸: 용수철 k 10 N/m (m_s 12 g), k 25 N/m (m_s 20 g) |
| 5 | 추 50 g · 100 g · 200 g · 아래 둘째 칸: 추 20 g · 150 g |
| 6 | 쇠공, 추 100 g |
| 7 (위) | 레이저 (650 · 532 · 405 nm 선택), 스크린 |
| 8 (위) | 이중 슬릿 d 0.10 · 0.20 mm, 단일 슬릿 a 0.10 mm |
| 7 (아래 둘째 칸) | 직류 전원 장치 (0~5 V) |
| 8 (아래 둘째 칸) | 마이크로 전류계, 광전관 세슘(W 2.14 eV) · 나트륨(W 2.28 eV) |

실험대 아래 수납장(양쪽 긴 면), 뒤쪽 벽 수납장, 폐시약 보관함도 모두 여닫는 칸이다 (준비실은 화학 실험용 — 시약장 추가 예정).
실험 테이블의 문 없는 짧은 옆면에는 **2구 콘센트**가 있다. 전원이 필요한 기기(레이저 등)는 전원선(2 m)이 닿는
콘센트에 꽂아야 작동한다 — 기기를 탭해 "전원 연결", 또는 콘센트를 탭해 "꽂기".

기구끼리는 **플러그 → 소켓**이 맞으면 연결된다. 물체를 든 채 다른 기구를 두 번 탭하면 끼워진다. 조준점 아래에
`[탭] 연결 · 클램프 → 스탠드 막대`처럼 표시된다.

| 들고 있는 것 | 탭할 곳 | 결과 |
|---|---|---|
| 클램프 | 스탠드 막대 (원하는 높이) | 그 높이에 고정, 팔이 나를 향함 |
| 실 | 클램프 집게 | 실이 늘어짐 |
| 용수철 | 클램프 집게 | 용수철이 매달림 (자기 무게로 조금 늘어남) |
| 추·쇠공 | 실 끝 고리 | 매달림 → **진자** |
| 추·쇠공 | 용수철 아래 고리 | 매달림 → **용수철 진자** |
| 추·쇠공·실·플라스크·레이저·광전관 | 클램프 집게 | 집게에 단단히 고정 |
| 슬릿판·스크린 | 클램프 집게 | 판 옆 가장자리를 물어 **세로로** 서고, 판이 팔 방향(나)을 향함 → 레이저는 팔 방향으로 쏘면 된다 |
| 각도기 | 클램프 | 받침점 뒤에 세워짐 |

연결된 기구를 들면 거기에 붙은 것도 함께 들린다. 조립된 기구 어디를 두 번 탭해도 **진자 실험** 등이 메뉴에 뜨고,
화면 왼쪽 위의 `▸ 진자 실험`, `▸ 간섭무늬 관찰` 버튼으로도 바로 열 수 있다.
두 번 탭 메뉴: 위치·방향(아래 광학 정렬 참고), 클램프 높이 ±1 cm,
레이저 파장·출력(1·3·5 mW), 전원 연결·뽑기, 도선 연결 시작·빼기.
오른쪽 위 🔍 버튼은 시야를 약 4배 확대한다 (mm 단위 무늬·눈금 보기).

### 이중 슬릿 간섭
레이저·슬릿판·스크린을 책상 위에 한 줄로 세우거나(높이가 맞게 만들어져 있음), 스탠드 + 클램프로 원하는 높이에 고정한다.
클램프를 막대에 끼울 때 `(높이 n cm)`가 표시된다 — 레이저 빛 높이는 책상에서 3.5 cm.
레이저를 콘센트에 꽂고 켜면 빛을 광선 추적으로 따라간다. 슬릿 중심에서 가로 ±2 cm, 세로 ±3 cm 안에 닿으면
미세 조정된 것으로 보고 통과해 회절·간섭된다 (벗어나면 왼쪽 위에 "빛이 슬릿 중심보다 … 를 지남" 안내).
무늬는 스크린뿐 아니라 벽·가구 등 빛이 닿는 어떤 면에도 고해상도 데칼로 비친다. Δy = λL/d 이므로 멀리 비출수록 넓다.
관찰 패널에서 확대된 무늬에 커서 A, B를 놓고 간격 수 n을 정하면 Δy = |B−A|/n, λ = d·Δy/L를 계산한다.
세기 분포는 I = I₀·cos²(πd sinθ/λ)·(sin β/β)², β = πa sinθ/λ.

### 역학 레일 · 수레
뒤쪽 벽 낮은 수납장 안에 레일(1.2 m, cm 눈금 — 오른쪽 끝의 가로로 긴 칸, 문을 아래로 젖혀 엶), 수레 A·B(각 500 g), 질량 막대 250 g × 4, 운동 센서 2개가 있다.
레일을 책상에 놓고 → 수레를 들고 레일을 두 번 탭(탭한 자리에 올라감) → 질량 막대를 들고 수레를 두 번 탭.
수레를 두 번 탭: 밀기 → / ←, 멈추기, 범퍼(자석 e≈0.95 · 용수철 e≈0.85 · 벨크로 달라붙음). 레일 두 번 탭: 기울기 ±0.5°.
`▸ 궤도 실험` 패널: 기울기 0 ~ 10°, 구름 저항 μ, 재생 속도(¼×까지·멈춤), 수레별 범퍼·미는 속력, 처음 자리로.
속도·가속도는 일부러 보여 주지 않는다 — 센서(추후)로 측정. 계산은 a = −g sinθ − μg cosθ·sign(v),
충돌은 운동량 보존 + 반발 계수 e (sim/track.ts), 수레별 (t, s, v)와 충돌 기록을 남겨 둔다.

### 화학 (준비실) — 산·염기, 지시약, pH
**시약장**(준비실 왼쪽, 약품 전용: 흰 철제 몸체에 문 전체가 유리 — 냉장고처럼 속이 보임, 위에 온도·습도 표시창, 아래 환기구): 0.1 M HCl · NaOH · CH₃COOH · NH₃, 증류수 2병, 지시약 3종(페놀프탈레인·메틸 오렌지·BTB), 만능 pH 시험지.
**유리 기구 보관장**(오른쪽): 뷰렛 2, 스탠드·클램프, 비커 6, 삼각 플라스크 2, 눈금실린더 2.
- 그릇을 들고 시약병 두 번 탭 → **받기**, 다른 그릇 두 번 탭 → **따르기** (슬라이더 한 칸 = 두 그릇 중 더 정밀한 눈금: 눈금실린더 0.5 mL, 뷰렛 0.05 mL, 비커 5 mL, 플라스크 10 mL). 시약병에는 다시 붓지 않는다.
- 지시약병을 들고 그릇 두 번 탭 → 1~3방울. pH 시험지 → 비교표로 읽은 대략의 pH(정수).
- 뷰렛: 클램프에 물리고 그릇을 끝 바로 아래 → 뷰렛 두 번 탭 → **콕 열기**(한 방울씩 0.05 · 천천히 0.2 · 빠르게 1 mL/s) / 콕 잠그기 / 정량 적하. 눈금은 위가 0 (읽은 값 = 50 − 들어 있는 양).
- **적정 곡선 (3.1)**: pH 센서(유리 기구 보관장)를 들고 그릇을 두 번 탭 → 전극이 입구 옆에 꽂힌다. 센서 또는 노트북을 두 번 탭해 연결 → 측정 프로그램에서 기록 시작 → 콕 열기.
  노트북이 (t, V, pH)를 기록 — V는 기록 시작 뒤 그 그릇이 뷰렛에서 받은 부피. pH–V / pH–t 그래프, ΔpH/ΔV 그래프,
  당량점(기울기 최대, 3 pH/mL 이상일 때), 당량점 pH, 반당량점 pH(약산이면 ≈ pKa), CSV.
  전극은 1차 지연(τ ≈ 1 s): 빠르게 흘리면 곡선이 늦게 따라와 오른쪽으로 밀린다 → 당량점 근처는 한 방울씩.
  액면이 전극 끝(바닥 바로 위)에 닿지 않으면 증류수를 더 넣는다 (몰수는 같아 당량점 부피는 그대로).
  검증: 0.1 M CH₃COOH 25 mL + 0.1 M NaOH → 시작 pH 2.88, 당량점 25.06 mL, 반당량점 pH 4.68 (빠르게 흘린 구간의 전극 지연으로 pKa 4.74보다 조금 낮음).
- 그릇 두 번 탭 → 눈금 읽기(그릇 정밀도만큼)와 색. 다 쓴 용액은 폐시약 보관함 위 폐액통에 — **무기**(HCl·NaOH·NH₃와 그 중화물) / **유기**(아세트산이 든 것). 잘못 고르면 버려지지 않고 알림창으로 이유를 알려 준다.

계산 (sim/chem.ts): 용액 = 부피 + 보존되는 성분 몰수(Na⁺, Cl⁻, 아세트산 총량, 암모니아 총량, 지시약).
pH는 전하 균형 [H⁺] + [Na⁺] + [NH₄⁺] = [OH⁻] + [Cl⁻] + [CH₃COO⁻]를 이분법으로 풀어 구한다 → 중화·약산·완충·가수분해를 한 식으로.
지시약 색은 비어-람베르트 흡광(A = ε·c·l, 투과율 10⁻ᴬ)을 빨강·초록·파랑으로 나눠 계산 → 섞인 지시약도 물리적으로 섞인 색.
한계: 이상 용액(활동도 = 농도), 부피 가산, 25 °C 고정.
검증: 0.1 M CH₃COOH pH 2.87, 반당량점 4.74(= pKa), 당량점 8.72 / HCl 25 mL + NaOH 24.90 → 3.70, 25.10 → 10.30.

### 뉴턴 운동 제2법칙 (도르래 + 추)
도르래(뒤쪽 수납장 칸 3, 바퀴 반지름 4 cm)를 레일 끝 받침에 끼우고, 추(20 ~ 200 g, 쇠공)를 도르래 실 끝에 걸면 도르래 쪽에서 가장 가까운 수레에 실이 묶인다.
수레는 잡힌 채로 기다리다가 **수레 놓기**(궤도 실험 패널, 수레·레일 두 번 탭)로 출발. 운동 센서는 반대쪽 끝에.
계산 (sim/track.ts): (M + m + I/r²)·a = m·g − M·g·sinθ − μ·M·g·cosθ − f_도르래 (실이 팽팽한 동안 한 덩어리).
추가 바닥·책상에 닿으면 실이 느슨해져 수레는 그때 속도로 굴러가고, 다시 멀어지면 추가 들린다.
패널: 이상적 a = mg/(M+m), 보정 a(도르래 관성 10 g·축 마찰 3 mN·구름 저항·기울기), 장력 T = M·a < mg.
검증: M 500 g, m 50 g → 운동 센서 x–t 2차 맞춤 a = 0.834 m/s² (보정 이론 0.835, 이상적 0.891).
추를 건 채 도르래를 레일에서 떼면 실이 감겨 추가 도르래 옆(받침 바닥 높이)에 따라온다 — 책상에 놓아도 추가 상판 위에 얹힌다.

### 직류 회로 (옴의 법칙 · 키르히호프 법칙 · 전구의 I–V)
부품(뒤쪽 수납장 칸 4~6): 직류 전원 장치(0 ~ 5 V, 내부 저항 0.05 Ω, 1 A 넘으면 정전류 CC), 저항 10·22·47·100 Ω(색띠),
꼬마전구 3.8 V 0.3 A 2개, 칼날 스위치, 전압계(내부 저항 10 MΩ, 0.001 V)·전류계(0.01 Ω, 0.1 mA) 2개씩. 극성 없는 단자는 놋쇠색, 그 사이 도선은 노랑.
계산 (sim/circuit.ts): 도선으로 이어진 단자 = 한 마디. 모든 마디에 키르히호프 전류 법칙(ΣI = 0)과 옴의 법칙 I = G·ΔV를 쓰면 G·V = I 연립방정식 → 가우스 소거(마디 전압법).
전원은 노턴 등가(E/r 전류원 ∥ 1/r)로 넣고, 전류가 1 A를 넘으면 정전류원으로 바꿔 다시 푼다.
전구 필라멘트: R(T) = R₀(T/300 K)^1.2, 열평형 I²R = c(T⁴ − T₀⁴) + k(T − T₀) (정격에서 복사 85 %·전도 15 %, 2700 K), 열용량으로 온도가 시간에 따라 변함 → 켜는 순간 돌입 전류.
패널(전원 장치·부품 두 번 탭 → 직류 회로 실험): 전압 조절, 계기 값(여러 개면 모두), 측정값 기록·자동 측정(0 → 5 V, 0.25 V 간격), I–V 그래프,
원점 지나는 직선 I = V/R 맞춤(R, 결정 계수)과 I ∝ Vⁿ 맞춤(로그–로그), CSV(V_V, I_mA, R_ohm). "부품별 실제 값 보기"로 정답 확인.
검증: 47 Ω, 3 V → 63.747 mA (이론 3/(47 + 0.061) = 63.747 mA), 자동 측정 R = 47.01 Ω·n = 1.001.
병렬(47 Ω ∥ 100 Ω) + 전구 직렬 → 전류계 1 = 전류계 2 + 47 Ω 갈래 전류 (KCL 오차 0), 전원 단자 전압 = 각 부분 전압의 합 (KVL).
전구 자동 측정: 1 V 165 mA(6.0 Ω) → 3.98 V 307 mA(13.0 Ω) → n ≈ 0.4 (맞춤 구간에 따라 달라짐 — 저전압에서는 거의 직선).
한계: 도선 저항 0, 계기 내부 저항 고정, 전구 필라멘트 끊어짐·전원 과열 없음, 교류·축전기·다이오드 없음.

### LED (문턱 전압 · 과전류)
LED 빨강 620 · 초록 525 · 파랑 465 nm (뒤쪽 수납장 칸 6). 모델: 쇼클리 식 I = I_s(e^{V_j/(nV_T)} − 1), n = 2, 직렬 저항 10 Ω, 20 mA에서 V_f ≈ 2.0 · 2.4 · 2.9 V.
비선형이라 회로 해석은 뉴턴 반복(접선 컨덕턴스 + 전류원, 접합 전압 변화 제한)으로 푼다.
접합 온도 dT/dt = (P·1000 K/W − (T − 25 °C))/0.3 s → 150 °C를 넘으면 타서 열린 회로(두 번 탭 → 새 LED로 교체).
패널: 전류 1 mA가 되는 문턱 전압을 보여 주고 빛알 에너지 hc/λ와 비교.
검증: 100 Ω 직렬 자동 측정 문턱 빨강 1.65 · 초록 2.04 · 파랑 2.54 V. 저항 없이 빨강에 2.2 V → 37 mA 105 °C, 2.4 V → 탐.
한계: 역방향 항복, 온도에 따른 V_f 변화(열 폭주) 없음.

### 힘 센서 · 포토게이트 (충격량 = 운동량 변화)
뒤쪽 수납장 칸 7. **힘 센서**는 레일 끝 받침에 끼우며, 수레가 부딪히면 범퍼를 미는 힘을 1 kHz로 기록한다(0.01 N, 잡음 ±0.02 N).
시뮬레이션(sim/track.ts)은 이때 순간 충돌 대신 범퍼가 눌리는 접촉을 0.5 ms 간격으로 적분한다: F = kδ(1 + 3(1 − e)/2 · δ'/v_in) (Hunt–Crossley).
범퍼 용수철 k = 500 N/m(충돌 ≈ 0.1 s) / 고무 k = 8000 N/m(≈ 0.025 s), 충돌 시간 ≈ π√(m/k).
**포토게이트**는 레일을 넘어가는 문 모양(레일 위 아무 곳이나, 1 cm 단위). 수레 가운데 차단판 폭 2.0 cm가 빛을 가린 시간 Δt → v = w/Δt (가림 시작·끝을 보간해 0.01 ms 단위).
측정 프로그램: 힘 센서 화면(전체 F–t, 충돌 고르기, 넓이 칠한 확대 그래프, J·최대 힘·충돌 시간·평균 힘, 같은 노트북의 운동 센서·포토게이트로 구한 Δp와 비교, 반발 계수),
포토게이트 화면(가림 기록 표, 두 게이트 사이 a = Δv/Δt와 (v₂² − v₁²)/2d). 노트북 한 대에 센서 4개까지.
검증(시뮬레이션만): J = mΔv 4자리까지 일치(0.5·1.0 kg, 0.3·0.6 m/s, 두 범퍼), 충돌 시간 99 ms / 24.5 ms (이론 99.3 / 24.8 ms).
브라우저 측정: 0.5 kg, 0.44 m/s — 용수철 J 0.412 N·s, 포토게이트 Δp 0.411(0.3 %), 운동 센서 Δp 0.413 / 고무 J 0.396, 포토게이트 0.396(0.1 %), 운동 센서 0.399.
두 게이트(30 cm) 사이 a = −0.039 m/s² = −μg (구름 저항 0.004).
고친 것: 되튀는 도중 속도가 0을 지날 때 "정지 마찰로 멈춤"이 적용돼 운동량이 조금씩 사라지던 문제(범퍼 힘이 있을 때는 적용하지 않음).

### 기하광학 · 백색광 · 마이컬슨 간섭계 (equipment/opticalElements.ts, beams.ts, sim/rayOptics.ts)
기구: 광학 원판(1° 눈금, 가운데 자리), 평면거울 3, 반투명 거울(50/50), 반원형 아크릴 블록(R 5 cm, n_D 1.490), 삼각 프리즘(플린트 60°, n_D 1.620),
볼록 렌즈 f = 10·20 cm, 오목 렌즈 f = −5 cm, 백색 광원(앞판: 한 줄 · 평행 세 줄 · 화살표 물체). 오른쪽 벽 보관장 위 선반·칸 6 아래.
광선 추적(매 변경마다): 광학 면은 식(평면·원통면·삼각기둥)으로 정의 → 스넬 법칙, 프레넬 반사(약한 갈래), 전반사, 반투명 거울 두 갈래,
이상적 얇은 렌즈, 분산 n(λ) = A + B/λ²(코시). 백색광은 처음 유리에 들어갈 때 400 ~ 700 nm 21줄로 갈라짐.
광선마다 광경로·빔 반지름·퍼짐각을 따라가 같은 레이저 빛이 한 곳에 겹치면(경로차 < 결맞음 길이 5 cm) 위상 합으로 간섭무늬(곧은 무늬 · 동심원).
화살표 물체는 얇은 렌즈 공식으로 스크린 위 상(배율 −D/a, 흐림 = 렌즈 반지름 × |1 − D/b|).
광학 패널(레이저·광원 두 번 탭 → 광선 경로): 면마다 입사각·나간 각, n = sin i / sin r, 전반사 임계각, 프리즘 꺾인 각(파장별), 렌즈 a·b·배율, 간섭 광경로차.
거울·반투명 거울 미세 조정 나사: 기울기 ±0.3°(0.001°), 이동 0 ~ 50 μm(0.01 μm).
검증: 아크릴 30° → 19.63°(n 1.488), 곡면 쪽 45°는 전반사·38°는 66.4°로 나감(임계각 42.2°); 플린트 프리즘 입사 50°: 400 nm 51.9°, 550 nm 48.9°(= 50 + 58.9 − 60), 700 nm 47.7°;
볼록 f 10 cm·a 20 cm → b 20 cm에서 선명한 거꾸로 선 상(배율 −1); 마이컬슨: 거울을 λ/8씩 밀면 가운데 밝기가 λ/2마다 되풀이, 기울기 0.03° → 곧은 무늬, 오목 렌즈 + 팔 길이 차 2 cm → 동심원.
한계: 편광(브루스터각·말뤼스 법칙), 렌즈 수차, 반투명 거울 두께, 광센서는 다음 단계(B).

### 광학 정렬 — 위치·방향 막대 (ui/placeBar.ts)
문제: 놓는 자리는 탭한 점, 회전은 1° 단위라 레이저 빛이 렌즈 중심을 지나게 놓기 어려웠다 (30 cm 앞에서 1° = 5 mm 비껴감).
놓인 기구 두 번 탭 → **위치·방향** 막대 (아래 가운데):
- 회전: 슬라이더(15°의 배수 ±2°에서 붙음), ±15° · ±1° · **±0.1°**
- 이동: ◀ ▲ ▼ ▶ = 화면 기준 왼쪽·멀리·가까이·오른쪽 (가장 가까운 세계 축으로), **1 cm / 1 mm** 단위. 원판에 끼운 기구는 원판째 움직인다.
  받쳐지지 않는 자리(책상 밖·다른 기구 위)로는 움직이지 않는다.
- 광학 기구(렌즈·거울·블록·프리즘, 이를 끼운 원판): 들어오는 빛줄기에서 기구 중심까지의 옆 거리 **빛–중심 ±x.x mm**
  (빛 진행 방향의 왼쪽 +, 5 cm 안의 빛만). **빛에 맞추기** → 중심을 빛줄기 위로 옮기고, 렌즈는 광축도 빛과 나란히 돌린다
  (거울·블록·프리즘은 각도가 실험 변수라 돌리지 않는다).
- 모든 조작은 명령 버스(call: setYawDeg · turnByDeg · nudge)로 → 되돌리기·멀티플레이어에 그대로 쓰인다.
검증(tests/07): 렌즈를 빛에서 7 mm·3° 비껴 놓음 → 표시 −7.0 mm, 빛에 맞추기 → 0.0 mm·0°, 1 mm 이동 → −1.0 mm, +0.1° → 0.1°, 책상 끝 밖 이동 거부.
한계: 빛 높이는 모든 기구가 3.5 cm로 맞춰져 있어 높이 정렬은 없음(클램프에 단 레이저는 높이 ±1 cm로). 빛이 5 cm 넘게 비껴가면 "빛에 맞추기"가 없다 — 먼저 대강 옮긴다.

### 칠판 쓰기 (world/chalkboard.ts, ui/boardEditor.ts)
칠판 아래 작은 받침(z 4.45 ~ 5.05)에 흰 분필·노란 분필·칠판 지우개. 분필(또는 지우개)을 들고 칠판을 탭하면 쓰기 화면이 열린다.
칠판은 가로 4.5 : 1로 길어서 절반씩(왼쪽·가운데·오른쪽) 크게 보며 쓰고, "전체"로 한눈에 본다. 지우개는 바탕색을 반투명으로 칠해 옅은 자국이 남는다.
획 하나 = 명령 `call(board, 'addStroke', 도구, 굵기, [x, y, …])` (칠판 비율 좌표) — 멀티플레이어에서도 같은 칠판을 함께 쓸 수 있는 모양.

### 명령 구조 (멀티플레이어 대비, src/net/commands.ts)
세계(실험실) 상태를 바꾸는 조작은 모두 **명령 객체**로 만들어 `bus.dispatch()`로 실행한다. 명령은 JSON으로 보낼 수 있는 모양이다
(물체 대신 만든 순서대로 붙인 이름표 `item12`, `item12/t0`(단자), `item6/s2`(소켓), `door3`, `outlet0`, `waste1`).

| 명령 | 쓰임 |
|---|---|
| `act {target, label}` | 대상의 동작을 이름으로 다시 찾아 실행 — 집기, 문, 전원, 스위치, 밀기, 콕, 센서 연결, 폐액 버리기 … |
| `use {item, target, label}` | 들고 있는 기구를 대상에 쓰기 (지시약 떨어뜨리기) |
| `place`, `attach` | 놓기 / 소켓에 끼우기 |
| `wire`, `unwire` | 도선 잇기 / 빼기 |
| `pour {src, dst, mL}` | 그릇 사이 옮기기 (따르기 막대의 확인) |
| `set {target, key, value}` | 패널 슬라이더 (전압, 기울기, `sim.airDrag`처럼 점 경로) |
| `call {target, method, args}` | 패널 버튼 (놓기, 기록 시작, 밀기 …) — 인자의 물체는 `{ref}` |

패널·막대 열기, 눈금 읽기, pH 시험지처럼 **내 화면에서만** 일어나는 동작은 `Action.local = true`로 표시해 명령으로 보내지 않는다.
동작을 이름(label)으로 다시 찾는 것은 일부러다: 실행 순간 상태가 바뀌어 그 동작이 없어졌다면(예: 다른 사람이 먼저 문을 닫음) 명령은 거절된다.
나중에 여럿이 하려면 `dispatch`만 "방장에게 보내기"로 바꾸고, 방장이 `execute`한 결과(상태)를 나눠 주면 된다. 디버그: `#debug`에서 `lab.bus.log`.

### 되돌리기 (src/net/undo.ts)
오른쪽 위 ↶ (PC: Ctrl+Z) = **내 마지막 조작 하나**. 다시 하기 없음.
방식: 명령마다 반대 명령을 짜지 않고, `bus.execute` 직전·직후의 배치 상태를 찍어 **바뀐 것만** 이전 값으로 기록한다
(act 명령은 이름으로 아무 동작이나 부르므로 반대 동작을 일일이 만들 수 없다).
- 배치 상태 = 기구마다 { 장면·소켓·손, 위치·방향(쿼터니언), 미끄럼 소켓 높이, 전원 콘센트, 숫자·참거짓·글자 설정값 } + 도선 목록 + set 명령의 이전 값.
- 되돌리지 않음: **화학**(용액 부피·몰수가 바뀌면 기록을 지우고 "화학 조작은 되돌리지 않음" 안내), 움직이는 중인 상태(속도·흔들림 → 정지 상태로), 측정 기록, 칠판, 보관장 문(바뀐 것 없는 조작은 앞 기록을 그대로 둔다).
- 여럿: 기구마다 마지막으로 바꾼 명령 번호 → 내 조작 뒤에 다른 사람이 같은 기구를 바꿨으면 거절. `undo`도 명령이라 방장이 실행.
검증(tests/08): 놓기 → 다시 손에, 1 mm 이동·12.3° 회전 → 오차 0, 끼우기·도선·전원·켜기·set 되돌림, 두 번째 되돌리기 없음, 따르기 10 mL는 그대로, p1이 뒤에 옮긴 렌즈는 p0이 되돌리지 못함.
한계: 손에 다른 것을 들고 있으면 "집기 전으로"는 못 돌린다(먼저 내려놓기). 기구 안쪽 물체 상태(예: 레일 시뮬레이션 내부 값)는 set·call 대상 필드가 아니면 남는다.

### 보관장 코드 · 실험 장비 배치 교재 (world/cabinet.ts setZone, content/placementBook.ts)

검증(tests/09): 칸 표 94개 + 보관장 밖 8개 + 교재 1 = 기구 103개(빠짐·중복 없음), 레이저 a-7 · 레일 b-1 · 0.1 M 시약 c-3 · c-4, 문 이름 a-1 · b-8 · d-6.
성능 진단: 설정 → "FPS·JS 시간·그리기 수" — JS 시간이 작은데 FPS가 낮으면 GPU(그리기 수·발열) 쪽, JS 시간이 크면 계산 쪽. 헤드리스 기준 시작 위치 그리기 약 190회, 준비실 약 770회.
**새 조작을 만들 때 규칙**: 상태를 바꾸는 코드는 Action.run(→ act 명령) 또는 `bus.set / bus.call`을 거친다. 패널에서 `target.x = …`로 직접 바꾸지 않는다.

### 센서 · 노트북 (측정 프로그램)
노트북은 칠판 앞 교탁 위 2대 + 스탠딩 테이블 위 1대(모두 같은 측정 프로그램). 센서는 노트북에 USB(2 m)로 연결해서 쓴다 (센서 두 번 탭 → 노트북에 연결).
**운동 센서**(초음파): 정면으로 가장 가까운 물체까지의 거리 x (0.15 ~ 3 m, 1 mm 단위). 레일 양 끝의 센서 받침에 끼우면 레일 방향을 본다.
노트북 두 번 탭 → **측정 프로그램**: 기록 시작·멈춤, 표본 10/20/30 Hz, 기록 시간, 계산 창(3 ~ 11점), 방향 반대,
x–t · v–t · a–t 그래프, 커서 A·B 구간의 Δx, 평균 속도, 가속도(x–t 2차 맞춤 / v–t 기울기), CSV.
v·a는 x에서 계산한 값: 창 안 점들의 직선 맞춤 기울기 (창이 넓을수록 매끄럽지만 충돌처럼 빠른 변화는 뭉개짐).
레일을 느리게 돌리면 기록 시각도 같은 배율로 흐르므로 측정값은 실제 물리량 그대로다.

### 용수철 진자
클램프 → 용수철 → 추. 당긴 거리 A를 정하고 **놓기**. 측정 주기 T를 이상적 2π√(m/k), 용수철 질량 보정 2π√((m + m_s/3)/k)와 비교한다.
추를 바꿔 가며 기록하면 **T²–m 그래프**의 기울기(4π²/k)에서 k, 절편에서 용수철 질량 m_s를 구한다.
추가 책상에 닿으면 놓을 수 없고, 탄성 한계를 넘거나 A가 정적 늘어남보다 크면 경고가 뜬다.

### 기록 내보내기·그래프
단진자·용수철·측정 프로그램의 **CSV** 버튼은 기록 표를 파일로 저장한다 (태블릿의 다운로드 폴더). 머리글·값은 영문·숫자만 써서 어떤 스프레드시트 앱에서도 깨지지 않는다.
단진자 기록 그래프: **T–√L** (θ₀ ≤ 20° 기록을 직선 맞춤 → g = (2π/기울기)²), **T/T₀–θ₀** (타원 적분 이론 곡선과 비교).

### 광전 효과
1. 레이저, 광전관, 전류계, 전원 장치를 책상에 놓고 레이저·전원 장치를 콘센트에 연결한다.
2. **도선**: 기구를 두 번 탭 → `도선 연결 시작 · +` → 이을 기구를 한 번 탭 → 단자 고르기 (단자를 직접 탭해도 됨).
   연결 중에는 단자에서 조준점까지 노란 미리 보기 선이 보인다. 빈 곳을 탭하면 취소.
   회로: 전원 + → 전류계 + → 전류계 − → 광전관 양극(A), 광전관 음극(K) → 전원 −. (도선 최대 1.5 m, 단자를 다시 탭하면 빼기. 도선은 빨강(+ 쪽)·파랑, 전원선은 회색. 선은 같은 면 위의 장비를 옆으로 돌아가고(길찾기), 책상 가장자리를 넘어 늘어진다)
3. 레이저를 광전관 창(음극)에 비춘다. 왼쪽 위 `▸ 광전 효과 실험`으로 패널을 연다.
4. 패널에서 전압 슬라이더·±0.01/0.1 V, **극성(정/역)** 으로 V_AK를 바꾸며 I–V 곡선을 그린다.
   역전압을 올려 전류가 0이 되는 전압을 **정지 전압 V_s로 기록** → 파장을 바꿔 반복 → V_s–f 그래프의 기울기에서 h, 절편에서 W.
eV_s = hf − W. 빛이 세지면 포화 전류만 커지고 V_s는 그대로, hf < W 이면(예: 650 nm) 아무리 세도 전류 0.

### 단진자 실험 패널
실 길이 ℓ, 처음 각도 θ₀, 적분 방법, Δt, 공기 저항을 정하고 **놓기**. 진자 길이는
L = ℓ + (고리 ~ 추 무게 중심)으로 자동 계산된다. 추가 책상에 닿는 길이면 실이 자동으로 짧아지고 안내가 뜬다.
측정 주기 T, 작은 각 근사 T₀ = 2π√(L/g), 타원 적분으로 구한 정확한 주기, 역학적 에너지 변화,
θ(t) 그래프, 기록 표를 보여 준다.
