조작 방법

칠판

칠판 아래 작은 받침(교탁 오른쪽 끝 너머)의 분필(흰색·노란색)이나 지우개를 집고 칠판을 탭 → 쓰기 화면: 손가락으로 쓰기, 보기(왼쪽·가운데·오른쪽·전체), 전체 지우기, 다 썼음.

되돌리기

오른쪽 위 ↶ = 내 마지막 조작 하나 되돌리기 (놓기·집기·끼우기·이동·회전·도선·전원·켜기·설정값). 다시 하기는 없다. 화학 조작(따르기·지시약)은 되돌리지 않는다 — 실제 실험처럼. PC는 Ctrl+Z.

실험 교재

교탁 위 물리 · 화학 실험 교재와 실험 장비 배치를 두 번 탭 → 교재 펼치기: 실험마다 목표 · 원리 · 방법 · 분석 · 시험 포인트 · 한계. 한 번 탭하면 들고 다닐 수 있다.

움직이기

  • 이동 화면 왼쪽 40%를 누른 채 밀기 (PC: WASD)
  • 둘러보기 나머지 영역을 드래그
  • 🔍 확대 시야를 약 4배 좁혀 눈금·무늬를 자세히 보기

한 번 탭

  • 놓인 기구 → 집기 (붙어 있는 기구도 함께 들림)
  • 들고 있을 때 책상·바닥 → 놓기 (호박색 고리 = 놓을 수 있음, 빨강 = 불가)
  • 문·보관장 문 → 열기/닫기, 콘센트 → 들고 있는 기기 꽂기·뽑기

두 번 탭 (또는 길게 누르기)

  • 놓인 기구 → 조작 메뉴: 실험 패널 열기, 전원 연결·뽑기, 켜기·끄기, 전압 조절, 파장·세기, 위치·방향(0.1° 회전·1 mm 이동), 높이 ±1 cm, 범퍼 바꾸기, 밀기, 도선 연결·빼기
  • 들고 있을 때 다른 기구 → 끼우기·매달기: 클램프 → 스탠드 막대, 실·용수철·레이저·슬릿 → 클램프 집게, 추 → 실·용수철 고리, 수레 → 레일, 질량 막대 → 수레

도선

  1. 기구를 두 번 탭 → 도선 연결 시작 · + (단자를 직접 두 번 탭해도 됨)
  2. 이을 기구를 한 번 탭 → 단자 고르기 (노란 선이 조준점까지 따라옴)
  3. 빈 곳을 탭하면 취소. 빼기는 기구 두 번 탭 → 도선 빼기

도르래 + 추 (뉴턴 운동 제2법칙)

  • 도르래(뒤쪽 수납장)를 들고 레일 끝을 두 번 탭 → 끝 받침에 끼움. 레일은 도르래 쪽 끝이 책상 가장자리 밖으로 나오게 놓는다. 추를 건 채 도르래를 떼면 실이 감겨 추가 도르래 옆에 따라온다
  • 추를 들고 도르래 실 끝을 두 번 탭 → 가장 가까운 수레에 실이 묶이고 수레는 잡힌 채로 기다린다
  • 운동 센서를 반대쪽 끝에 끼워 기록 시작 → 궤도 실험 패널(또는 수레 두 번 탭)에서 수레 놓기

직류 회로 (옴 · 키르히호프)

  • 뒤쪽 수납장 칸 4~6: 직류 전원 장치, 저항 10·22·47·100 Ω, 꼬마전구 2개(3.8 V 0.3 A), 스위치, 전압계·전류계 2개씩
  • 도선으로 한 고리를 만든다: 전류계는 재려는 부품과 직렬, 전압계는 병렬. 스위치는 두 번 탭 → 닫기·열기
  • 전원 장치(또는 부품)를 두 번 탭 → 직류 회로 실험: 전압 조절, 계기 값, 측정값 기록·자동 측정(0 → 5 V), I–V 그래프와 R·n 맞춤, CSV
  • 전원 장치는 1 A를 넘으면 전류 제한(CC)으로 바뀐다 — 화면에 CC가 뜨면 단락을 의심
  • LED 3색(칸 6): 빨강 단자(+)를 전원 + 쪽으로. 직렬 저항 없이 문턱을 크게 넘기면 과열로 탄다 → 두 번 탭해 새 LED로 교체

기하광학 · 간섭계

  • 오른쪽 벽 보관장 위 선반: 광학 원판·반원 블록(칸 4), 거울 3개·렌즈 3개(칸 5), 반투명 거울·프리즘(칸 7), 백색 광원(칸 6 아래)
  • 기구를 들고 광학 원판을 두 번 탭 → 가운데에 끼움, 두 번 탭 → 위치·방향(0.1°)으로 입사각 조절. 원판 눈금으로 각을 읽는다
  • 정렬: 렌즈·거울 등을 두 번 탭 → 위치·방향 막대에 빛–중심 거리(mm)가 뜬다. ◀▲▼▶(1 cm / 1 mm)로 옮기거나 빛에 맞추기 → 중심을 빛 위로 (렌즈는 광축도 나란히)
  • 레이저·백색 광원 두 번 탭 → 광선 경로: 면마다 입사각·굴절각, n 계산, 프리즘 꺾인 각, 렌즈 상, 간섭 경로차
  • 백색 광원 앞판(두 번 탭): 한 줄 · 평행 세 줄 · 화살표 물체. 거울·반투명 거울 두 번 탭 → 미세 조정 나사(마이컬슨 간섭계)

센서 · 노트북

  • 센서를 두 번 탭 → 노트북에 연결 (USB 2 m, 노트북 한 대에 센서 4개까지)
  • 운동 센서를 들고 레일 끝을 두 번 탭 → 센서 받침에 끼워져 레일 방향을 바라봄 (측정 범위 0.15 ~ 3 m)
  • 노트북을 두 번 탭 → 측정 프로그램: 기록 시작·멈춤, x·v·a 그래프, 커서 A·B 구간 분석, CSV
  • 힘 센서(칸 7): 레일 끝 받침에 끼움, 1 kHz로 F–t 기록 → 충돌마다 충격량 ∫F dt. 두 번 탭 → 범퍼 용수철/고무
  • 포토게이트(칸 7): 들고 레일을 두 번 탭 → 레일을 넘어가게 걸림. 수레 차단판(2.0 cm)이 가린 시간 → v, 두 개면 가속도

화학 (준비실)

  • 그릇을 들고 시약병을 두 번 탭 → 받기, 다른 그릇을 두 번 탭 → 따르기: 슬라이더로 부피 선택 (한 칸 = 눈금실린더 0.5 mL, 뷰렛 0.05 mL, 비커 5 mL)
  • 시약병에는 다시 붓지 않는다. 지시약병·pH 시험지를 들고 그릇을 두 번 탭 → 방울 떨어뜨리기·pH 확인
  • 뷰렛은 스탠드·클램프에 물린 뒤 그릇을 끝 바로 아래에 두고 뷰렛을 두 번 탭 → 콕 열기(한 방울씩 0.05 · 천천히 0.2 · 빠르게 1 mL/s) / 콕 잠그기 / 정량 적하
  • 적정 곡선: pH 센서를 들고 그릇을 두 번 탭(전극 꽂기) → 센서나 노트북을 두 번 탭해 연결 → 측정 프로그램 "기록 시작" → 콕 열기. pH–V 그래프와 당량점·반당량점이 자동으로
  • 그릇 두 번 탭 → 눈금 읽기. 다 쓴 용액은 그릇을 들고 폐시약 보관함 위 폐액통을 탭 — 무기(파랑: HCl·NaOH·NH₃와 그 중화물) / 유기(노랑: 아세트산이 든 것). 잘못 고르면 버려지지 않는다

전원

전원이 필요한 기기(레이저, 직류 전원 장치)는 실험 테이블 짧은 옆면의 콘센트에 꽂아야 작동한다. 전원선은 2 m, 도선은 1.5 m — 더 멀어지면 빠진다.

기구 위치 · 보관장 코드

보관장 칸마다 코드가 붙어 있다: a 실험 기구 보관장(오른쪽 벽) · b 실험 기구 수납장(뒤쪽 벽) · c 시약장 · d 유리 기구 보관장. a-3 = a의 3번째 칸(앞에 서서 왼쪽부터). 코드 판은 칸 맨 위 문에 있고, 문을 조준해도 뜬다. 교탁 위 실험 장비 배치 교재에 칸별 기구와 실험별 준비물 위치가 있다.

주 실험실 오른쪽 벽 보관장: 스탠드·클램프·실·용수철·추·레이저·슬릿·스크린, 아래 칸(불투명 문)에 전원 장치·전류계·광전관. 뒤쪽 벽 낮은 수납장(문을 열어 꺼냄): 레일(오른쪽 끝 넓은 칸), 수레·질량 막대, 운동 센서, 도르래, 직류 회로 부품(전원 장치 2·저항·전구·스위치·전압계·전류계). 노트북: 교탁 위 2대, 스탠딩 테이블 위 1대. 실험 교재: 교탁 위. 실험대 아래 수납장도 모두 여닫을 수 있다. 준비실: 시약장(시약·지시약·pH 시험지), 유리 기구 보관장(뷰렛·비커·플라스크·눈금실린더·스탠드·pH 센서). 레일은 뒤쪽 수납장 오른쪽 끝의 가로로 긴 칸(문을 아래로 젖혀 엶).

실험 패널

기구가 실험할 수 있게 조립되면 화면 왼쪽 위에 ▸ 실험 이름 버튼이 뜬다. 패널은 한 번에 하나, 화면 오른쪽에 열린다.
